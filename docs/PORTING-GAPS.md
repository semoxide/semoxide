# Porting gaps

What semantic-release does that semoxide can't reproduce in Rust, and what semoxide does instead. Overview: [semantic-release §6](research/semantic-release.md#6-rust-port-notes). `semoxide migrate` ([ADR 0001](decisions/0001-compatibility-stance.md)) reports every gap it hits in a `.releaserc`.

Status: an ADR link means decided; **open** means only a recommendation exists, listed under [Open decisions](#open-decisions) (O1–O13).

| # | Gap | semantic-release behavior | Why not portable as-is | semoxide replacement | Status |
|---|---|---|---|---|---|
| 1 | JS config files | cosmiconfig: `.releaserc*`, `release.config.(js\|ts\|mjs\|cjs)`, `package.json#release` ([spec §3](specs/SEMANTIC-RELEASE-SPEC.md#3-configuration)) | Options can be computed or be functions | `semoxide.toml` (fallback `.config/semoxide.toml`), data only, layered | [0002](decisions/0002-config-format.md) |
| 2 | Plugin loading | `import()` of npm modules, CJS/ESM interop, inline function plugins ([flow](research/semantic-release.md#plugin-loading-and-normalization)) | No JS runtime; no JS bridge ([0001](decisions/0001-compatibility-stance.md)) | Process plugins speaking gRPC over a local socket (Unix socket / named pipe, never stdio), version-pinned binaries downloaded with a checksum lock; Rust plugins also ship as crates that run in-process (commit-analyzer and release-notes bundled by default) | [0010 §Decided](decisions/0010-plugin-architecture.md#decided) |
| 3 | Shareable configs | npm packages; plugins resolved relative to the config package ([spec §10](specs/SEMANTIC-RELEASE-SPEC.md#10-shareable-configs)) | npm resolution | `extends` layer ([0002](decisions/0002-config-format.md)); plugins come from pinned versions, not from the config package ([0010](decisions/0010-plugin-architecture.md#decided), "Getting plugins"). Sources: presets, local paths, pinned git refs; URLs later ([0014](decisions/0014-porting-behaviour.md)) | 0002, 0010, 0014 |
| 4 | lodash templates | `${...}` / `<% %>` run JS in `tagFormat`, branch props, git `message`, exec `*Cmd`, github templates ([dependencies §10](research/dependencies.md#10-lodash-template-usage)) | `new Function` eval | minijinja; `{version}` for `tag_format`; no JS expressions | [0004](decisions/0004-template-engine.md) |
| 5 | User JS functions | writer `transform`, `finalizeContext`, sort comparators ([writer](research/dependencies.md#3-conventional-changelog-writer-921)); `releaseRules` as a JS module, function rules (#627) ([analyzer §5](research/commit-analyzer.md#5-rust-port-notes)) | Code as config | Declarative TOML + minijinja template logic; a replacement plugin for anything more ([0014](decisions/0014-porting-behaviour.md)) | 0010, 0014 |
| 6 | Handlebars and preset modules | `conventional-changelog-<preset>` npm modules, `.hbs` partials, presets called as functions ([version skew](research/dependencies.md#0-version-skew-read-first), [presets](research/dependencies.md#4-presets)) | npm resolution; upstream is mid-migration from Handlebars | User templates in minijinja, `.hbs` unsupported ([0004](decisions/0004-template-engine.md)); presets live in the bundled `semoxide-plugin-commit-analyzer` / `-release-notes` crates ([0010](decisions/0010-plugin-architecture.md#decided)). Presets: `conventionalcommits` (default) + `angular` ([0014](decisions/0014-porting-behaviour.md)) | 0004, 0010, 0014 |
| 7 | micromatch globs | Default maintenance branch `+([0-9])?(.{+([0-9]),x}).x` (extglob); releaseRules globs where `*` stops at `/` (#175); git `assets` ([analyzer §3](research/commit-analyzer.md#3-algorithm)) | `globset` has no extglob; path semantics differ | Context-specific `globset`; built-in maintenance matcher ([0014](decisions/0014-porting-behaviour.md)) | 0014 |
| 8 | node-semver ranges | `satisfies`, `validRange`, `x` ranges, prerelease rules, `-0` upper-bound quirk, `inc`, `diff` ([dependencies](research/semantic-release.md#5-dependencies)) | `semver` crate has Cargo ranges and no bump API ([SemVer §6](specs/SEMVER-SPEC.md#6-implementation-notes-for-semoxide)) | `semver` crate + own range and bump code ([0014](decisions/0014-porting-behaviour.md)) | 0014 |
| 9 | Regex lookaround | Parser regexes use lookahead; users pass JS regexes via `parserOpts` ([parser §1](research/dependencies.md#1-conventional-commits-parser-712)) | `regex` crate has no lookaround or backrefs | Built-in parser wraps `git-conventional` ([0006](decisions/0006-cc-parser.md)). User patterns: `fancy-regex` with a backtrack limit ([0014](decisions/0014-porting-behaviour.md)) | 0006, 0014 |
| 10 | Secret masking | `hook-std` patches global `process.stdout`/`stderr`; masks raw and URL-encoded forms ([spec §6](specs/SEMANTIC-RELEASE-SPEC.md#6-ci-git-and-auth), [side effects](research/semantic-release.md#4-side-effects)) | No global stdout patching in Rust | Decided for plugins: manifest-declared secrets are registered for masking; plugin stdout/stderr (incl. children) is captured as masked log lines; in-process plugins log only via the masked `Log` API ([0010](decisions/0010-plugin-architecture.md#decided)). Everything else: masking at source plus an output pass, name-pattern scan, `mask_env`, `RegisterSecret`, base64 forms ([0013](decisions/0013-observability.md)) | 0010, 0013 |
| 11 | Mutating `process.env` | Core sets `GIT_ASKPASS`, `GIT_TERMINAL_PROMPT`, `GIT_AUTHOR_*`/`GIT_COMMITTER_*` on the caller's env ([run order](research/semantic-release.md#run-internals)) | Library anti-pattern; `set_var` is `unsafe` in edition 2024 | git2 is the only backend, no git CLI ([0011](decisions/0011-git-backend.md)), so no askpass env; git credentials stay in the host and plugins push via the host `Git` service. A plugin's env is built: system vars + its manifest secrets + the per-run token ([0010](decisions/0010-plugin-architecture.md#decided), "Environment and secrets", "Host services"). Core env: explicit snapshot ([0013](decisions/0013-observability.md)); bot identity: O8 | 0010, 0011, 0013; bot identity **open** |
| 12 | env-ci | JS lib, ~31 CI vendors, reads event JSON ([dependencies §5](research/dependencies.md#5-env-ci)) | No equivalent crate (`ci_info` lacks branch/PR semantics) | O9 | **open** |
| 13 | `npm` CLI dependency | Bundled `npm` for version/pack/publish/whoami/dist-tag, temp npmrc ([npm §5](research/npm.md#5-rust-port-notes)) | Packing, lifecycle scripts and provenance only exist in the CLI | npm is not in the first official plugin set ([0010](decisions/0010-plugin-architecture.md#decided)). When built it must be a process plugin (runs external tools) whose manifest secrets reach `npm` children via env. Mechanism: O10 | 0010 (deferred); mechanism **open** |
| 14 | Error semantics | `SemanticReleaseError` flag gates `fail`; `AggregateError` flattening ([aggregation](research/semantic-release.md#error-aggregation), [error §9](research/dependencies.md#9-semantic-releaseerror)) | Duck-typed marker flag on any thrown object | Errors from several plugins on one step are collected ([0010](decisions/0010-plugin-architecture.md#decided)); a failure after the tag push runs `rollback` ([0012](decisions/0012-partial-failure.md)). Error type, `fail` gating (always runs) and partial-failure exit code 5: [0013](decisions/0013-observability.md) | 0010, 0012, 0013 |
| 15 | JS API | `semanticRelease(options, {cwd, env, stdout, stderr})` → `Result \| false` ([spec §8](specs/SEMANTIC-RELEASE-SPEC.md#8-js-api)) | Node streams, untyped options bag | Embedders register in-process plugin crates in the builder ([0010](decisions/0010-plugin-architecture.md#decided), "Embedders"). Rest of the API: O12 | 0010; rest **open** |
| 16 | `localeCompare` sorting | Writer sorts groups, commits and notes with `localeCompare` ([writer](research/dependencies.md#3-conventional-changelog-writer-921)) | ICU collation, not byte order | O13 | **open** |

## Open decisions

Each entry is a **recommendation (not decided)**; the user decides.

1. **O1 `extends` sources (#3): decided** in [0014](decisions/0014-porting-behaviour.md).
2. **O2 User functions (#5): decided** in [0014](decisions/0014-porting-behaviour.md).
3. **O3 Preset set (#6): decided** in [0014](decisions/0014-porting-behaviour.md).
4. **O4 Globs (#7): decided** in [0014](decisions/0014-porting-behaviour.md).
5. **O5 Ranges (#8): decided** in [0014](decisions/0014-porting-behaviour.md).
6. **O6 User regexes (#9): decided** in [0014](decisions/0014-porting-behaviour.md).
7. **O7 Secret masking (#10): decided** in [0013](decisions/0013-observability.md).
8. **O8 Bot identity (#11):** commit author/committer for commit-back. Recommendation (not decided): a git2 `Signature` from config, defaulting to a semoxide bot identity. Core env is decided ([0013](decisions/0013-observability.md)).
9. **O9 CI detection (#12):** own table-driven env-ci port as a separate module/crate, git fallback via git2.
10. **O10 npm (#13):** shell out to the user's package manager for pack/publish; native HTTP for whoami, OIDC and dist-tags; no temp `.npmrc`.
11. **O11 Errors (#14): decided** in [0013](decisions/0013-observability.md): structure, display, aggregation, exit codes; `fail` always runs with known/unexpected marking.
12. **O12 Library API (#15):** `Semoxide::builder()` taking config layers, `cwd`, env map, output sinks and plugins; returns `Result<Option<Release>>` (`None` = no release).
13. **O13 Sort order (#16):** case-insensitive comparison with byte-order tiebreak, documented as a difference.
